# LUMEN — Curated Technology E-Commerce Website

LUMEN is a modern frontend e-commerce website designed for browsing and purchasing curated technology products such as smartphones, laptops, audio devices, smart-home products, cameras, wearables, gaming accessories, and computer accessories.

The project focuses on creating a polished, realistic online shopping experience with product discovery, filtering, product details, wishlist management, cart management, checkout, and order confirmation flows.

> **Project Type:** Frontend E-Commerce Website  
> **Status:** Frontend / Interactive Prototype  
> **Checkout:** Simulated — no real payment is processed

---

## Overview

LUMEN is designed around the idea of a curated technology store rather than a conventional marketplace.

The website uses a clean editorial-style interface with a combination of warm neutral tones, dark green sections, soft pink surfaces, rounded cards, and prominent typography.

The goal of the project was to build a complete frontend shopping journey — from discovering a product to completing a simulated order.

The website demonstrates how different e-commerce screens and interactions can be connected into one consistent user experience.
